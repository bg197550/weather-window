# weather-window
NOAA outlooks and local forecasts for Utah and New England

## What's on the dashboard

- **At a glance** (default): active NWS watches, warnings and advisories for every location, plus current observations and the next three forecast periods for Park City and Boston.
- **Utah / New England forecasts**: alert banners, nearest-station observations, NWS point forecasts, a 48-hour hourly chart (temperature, precipitation chance, wind, snow/rain markers), detailed forecast, full Area Forecast Discussion, colorblind-safe model comparison (line styles, marker shapes and end labels, not color alone), and for Utah the mountain profile and a **Resort snow** table (NWS gridded snowfall next 24/48/72 h at mid-mountain and peak for every resort, lowest snow level, Utah Avalanche Center links).
- **Radar**: NOAA NEXRAD base reflectivity loop (last 50 minutes) from the Iowa Environmental Mesonet on an OpenStreetMap basemap, with presets for the Wasatch, northern Utah, Boston, and southern/northern New England, plus links to the NWS station loops.
- **Long range**: CPC outlook maps and the briefing generated by `scripts/update-long-range.mjs`. The page flags the briefing as stale if it is more than 12 hours old or if parts could not be refreshed.

The URL keeps the current tab, location and view (for example `#utah/deer-valley/mountain`), so views can be bookmarked. Open pages refresh their data every 15 minutes while visible. No API keys are used.

The long-range script parses each CPC horizon and each region's ensemble guidance independently. If a source is unreachable or CPC's wording no longer matches, it keeps the previous data for that part and records it in `warnings` instead of failing the whole run.
